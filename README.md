# note-to-summary

A Codex skill for writing an English, topic-level literature review from academic PDFs, Markdown notes, or both.

Provide the source files and a topic. The skill synthesizes research questions, methods, findings, and open questions into one Markdown review, with author-year citations when the sources support them. You can also specify the output path; otherwise, the review is saved in the working folder as `<topic>-literature-review.md`.

The skill instructions are in [SKILL.md](SKILL.md).
